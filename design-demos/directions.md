# CleanSweep · 六张方向卡

共同输入：`spec.md`。共同内容：6 个已安装软件（7-Zip / Chrome / Edge 受保护 / VS Code / Spotify /
Security Update 受保护）、选中 Chrome 的详情、AI 已启用、管理员已提权。基准 1280×800。

轮盘秒数 S=1 → web 分区 1%20+1=**2 号（新粗野主义）**，east 分区 1%12+1=**2 号（宋刻本）**。

---

## 逻辑一 · 最佳设计师 ×2

### A｜Teenage Engineering · 仪器面板 `大胆`

- **逻辑与来源**：Teenage Engineering（瑞典斯德哥尔摩，OP-1 / EP-133 的工业设计团队）。
  他们的核心不是"好看"，是**把参数面板做成能读的产品**：丝印小标签、刻度、拨档、
  状态灯、模块化边框。清理工具的本质就是读一台机器的参数，气质完全对得上。
- **借的是什么**：
  1. 标签用 10–11px 全大写 + 字距 +0.08em，永远贴在数值的正上方，成对出现（`INSTALLED` / `6`）
  2. 分区靠 1px 硬边框切块，块与块之间不留渐变、不留阴影
  3. 导航做成"拨档"：一列等宽的分段块，选中项左侧一条 3px 实心琥珀 + 反白底
  4. 状态只允许三种灯：实心（正常）、空心（不可用）、半亮（受限），不用图标
- **主角素材**：数据读数本身（软件名当主读数、大小/来源当副读数）。
  程序化图形：左侧导航底部的"容量刻度尺"（0–100% 的等分段），显示已列出的软件总大小。
- **骨架**：顶栏（仪器名 + 当前档位 + 三个状态灯）→ 左 200px 拨档列 → 主区上部一条"读数条"
  （共 6 项 / 受保护 2 / 合计 1.9 GB）→ 下部软件清单（每行左读数右操作）。
- **胆量花在哪**：左侧拨档列 + 底部容量刻度尺。其余全部收敛成灰底黑字。
- **form 来自内容的哪里**：清理工具读的是"系统读数"，所以界面长成一台仪器，而不是一个网站。

### B｜Vignelli · 瑞士网格 `克制`

- **逻辑与来源**：Massimo Vignelli（Unimark / Vignelli Associates；1972 纽约地铁图、
  Knoll 手册、Heller 的《The Vignelli Canon》）。他信一件事：**网格解决一切，颜色只准一个**。
- **借的是什么**：
  1. 12 栏刚性网格，纵向基线 8px，任何元素都落在网格线上
  2. 字号只用四级：32 / 16 / 13 / 11，不出现中间值
  3. 全页只有一个颜色（琥珀），且**只出现在可点击/当前状态**上；其余纯灰阶
  4. 分隔用 1px 线，不用卡片、不用圆角、不用阴影
- **主角素材**：巨型标题「已安装 6」当首屏主视觉（纯排版，零图形）。
- **骨架**：左侧 160px 只放四个纵向文字入口（不用图标）→ 主区 12 栏：
  标题跨 5 栏、清单跨 7 栏，详情用右侧 4 栏，全用竖线分开。
- **胆量花在哪**：一个 64px 的数字「6」直接压住整个清单标题区，其余全部 13px。
- **form 来自内容的哪里**：卸载是台账，台账就该是网格；软件名与发布者的对齐关系是内容自带的。

## 逻辑二 · 现实参照 ×2（已亲眼看，截图在 `refs/`）

### C｜Linear 的产品界面 `中性` `refs/linear.png`

- **逻辑与来源**：Linear（linear.app，2024 年整站改版；截图见 `refs/linear.png`）。
  同媒介里"专业工具做到最克制"的当代标杆：一个 issue 列表 + 属性栏，撑起整个产品。
- **借的是什么**：
  1. **三级暗色**：`#0A0A0B`（底）/ `#111113`（面板）/ `#1A1A1D`（悬浮）——
     层次靠明度差 4–6%，不靠边框
  2. 侧栏 **240px 带文字**，分组小标题 11px 灰字（`Workspace` / `Favorites` 那种），行高 30px
  3. 右侧属性栏：label 11px 灰、value 13px 白，成对排列，垂直间距 12px
  4. 状态用「圆点 + 词」而不是徽章（`● In Progress`），颜色只给圆点
  5. pill 标签：深底 + 8px 圆点 + 12px 字，圆角 3px
- **主角素材**：列表本身。没有插画，没有图形，全靠排版层级。
- **骨架**：左 240px 侧栏（四个入口带文字 + 分组标题「管理」「系统」）→ 中间列表
  （每行：名称 / 发布者·版本 / 来源 / 大小）→ 右侧 320px 详情栏（**未选中时不空白**，
  显示"这台机器的状态"：AI / 管理员 / 可清理项数）。
- **胆量花在哪**：右栏未选中态做成"机器体检卡"，把原来的空白变成信息。
- **form 来自内容的哪里**：软件清单与 issue 列表同构——都是"一列对象 + 右侧属性"。

### D｜Zed 编辑器的界面语言 `中性` `refs/zed.png`

- **逻辑与来源**：Zed（zed.dev，Rust 写的协作编辑器；截图见 `refs/zed.png`）。
  它把"多面板工具"处理得极干净：全靠 1px 细线分区，产品本身就是主角。
- **借的是什么**：
  1. **分区只用 1px 线**，不用卡片不用阴影；线与线之间的间距就是唯一的留白手段
  2. 顶栏 44px + 底部**状态栏 24px**（编辑器惯例：常驻状态，不占内容区）
  3. 分区标题：无衬线 13px 600 + 右侧 11px 灰字补充说明（`Fast` / `Written from scratch in Rust…`）
  4. 细线网格把页面切成不等宽的三栏，栏内文字左对齐、不居中
- **主角素材**：横向细线构成的"仪表盘骨架"。
- **骨架**：顶栏 44px（logo + 四个文字 tab + 右侧 AI/管理员状态）→ 主体左右两栏用竖线分
  （左 62% 清单 / 右 38% 详情）→ 底栏 24px 状态条（`管理员 ✓ · AI 已启用 · 6 项 · 扫描就绪`）。
- **胆量花在哪**：底部常驻状态栏 + 顶栏四个 tab 用等宽字排（像终端的标签页）。
- **form 来自内容的哪里**：清理是一次"运行"，运行就该有状态栏。

## 逻辑三 · 秒数轮盘 ×2

### E｜新粗野主义 `大胆`（web #2，色彩降级）

- **逻辑与来源**：轮盘 web #2 = 新粗野主义撞色信息流（The Verge 2022 改版，PolySans + Mānuka；
  样张 `assets/style-specimens/web/02-neo-brutalism.jpg`）。
  **降级说明（还原 85%→70%）**：原风格的高饱和撞色（电光紫/品红/亮黄）与"克制仪器"语境冲突，
  颜色收敛为 graphite + 琥珀，只保留它的**骨架**：模块网格、2px 硬描边、硬投影、零圆角、标签方框。
- **借的是什么**：
  1. 2px 实心边框 + `box-shadow: 4px 4px 0` 硬投影（无模糊）
  2. 模块网格：不等宽的格子拼装，格子之间 8px 缝
  3. 标签做成小方框（1px 边框里的 10px 大写），压在内容左上角
  4. 字号极端反差：格子里的大数字 44px vs 说明 11px，没有中间层
- **主角素材**：一个"盘点磁贴"——总项数作为 44px 大数字，配琥珀底黑字。
- **骨架**：顶栏（硬边框）→ 磁贴网格 4 格（总项数 / 受保护 / 可清理大小 / AI 状态）→
  下方清单（也带 2px 边框，行间用实线）。
- **胆量花在哪**：整页没有一个圆角，边框和硬投影贯穿到底。
- **form 来自内容的哪里**：清理是"盘点库存"，磁贴就是库存标牌。

### F｜宋刻本版式 `安静`（east #2）

- **逻辑与来源**：轮盘 east #2 = 宋刻本叶面形制（版框、界栏、鱼尾、朱批；
  样张 `assets/style-specimens/east/02-song-block-print.jpg`）。
- **借的是什么**：
  1. 外粗内细的**双线版框**包住整个内容区
  2. **界栏**：每列之间一条细竖线，信息被格线框住，不靠留白分区
  3. **鱼尾**：分区中缝上放倒三角标记 + 竖排小字标题
  4. **朱批**：受保护项用朱红小点标在天头一侧（不用整行变色）
  5. 纸色底 + 墨黑字 + 一个朱红
- **主角素材**：格线系统本身（版框 + 界栏 + 鱼尾）。
- **骨架**：整页一个版框，内部左右两栏：左栏（软件名 / 发布者 / 版本，竖排感）、
  右栏（来源 / 大小 / 状态 / 操作），栏间细线，行间细线。
- **胆量花在哪**：把桌面工具排成一本账册，朱点当风险标记。
- **form 来自内容的哪里**：卸载历史本质是账册，刻本是中国最成熟的账册形态。

## 挑三张做完整版

| 方向 | 单看够好 | 彼此不一样 | 撞账本 | 用力过头 | 结论 |
|---|---|---|---|---|---|
| A 仪器面板 | ✓ 骨架硬朗、可落地 | 与 B/C/D 完全不同（拨档 + 读数条） | 账本空 | 否 | **做** |
| B 瑞士网格 | ✓ 但太像现状 | 与 C/D 同属"规整网格" | — | 否 | 缩略图备选 |
| C Linear | ✓ 最稳最可用 | 与 D 同为暗色专业工具，但 C 是"三级明度"、D 是"细线" | 账本空 | 否 | **做** |
| D Zed | ✓ | 与 C 骨架接近（左列右详），差异在状态栏 | 账本空 | 否 | 缩略图备选 |
| E 新粗野 | ✓ 骨架差异最大 | 唯一"磁贴盘点"型 | 账本空 | 边缘（已降级色彩） | **做** |
| F 宋刻本 | 气质独特但密度与可读性风险高，落地到 React 会难看 | 唯一"账册"型 | 账本空 | **是**（整页做成刻本） | 缩略图备选 |

选 **A / C / E**：三个骨架（仪器读数 / 三级暗色列表 / 磁贴盘点）互不重叠，气质分别是
硬朗、克制、大胆。F 的手法去掉后信息反而更清楚，属于用力过头，做成缩略图留作备选。
