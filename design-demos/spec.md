# CleanSweep 界面重设计 · Spec

> 这是三个方向的共同输入。只写「要说什么」，不写「长什么样」——长什么样是方向卡的事。

## 项目是什么

CleanSweep（windows-clean）：Windows 软件卸载与残留清理工具。Tauri 2 + React + Rust，本机运行，
需要管理员权限，AI 可选（不可用时会阻止卸载）。

## 受众与场景

**受众**：Windows 高级用户、开发者、装机/维护自己机器的人。不是给电脑小白的一键加速器。
**场景**：每隔一段时间清理软件；或某个软件装坏了想连根拔掉。
关键决策只有两个——**「这个能不能删」** 和 **「删干净了没有」**。
两个决策都在有风险的前提下做，所以界面要让人敢按，但不能让人误按。

## 核心信息（优先级从高到低）

1. 这台机器上装了什么，哪些是受保护的（删不掉）
2. 选中的这款软件是什么，删了有什么风险（AI 分析结论）
3. AI 是否可用——**不可用则不能卸载**，这是硬约束，不是提示
4. 删完之后还剩什么（残留逐项审核：可删 / 谨慎 / 保留）
5. 是否以管理员身份运行（影响操作能否成功）
6. 不可逆操作需要二次确认，确认框要写清「会发生什么」

## 情感基调

**克制的专业仪器**。不讨好、不娱乐、不用吉祥物、不做进度条彩带。
像终端和任务管理器之间的东西：信息密度高、状态不撒谎、危险动作有分量。
参考气质：Linear 的克制、Zed 的仪器感、Windows Terminal 的密度。

## 输出格式与尺寸

- 桌面应用窗口，基准 **1280×800**，要能在 **1024×700** 下不破版
- 三个方向统一这个尺寸，否则没法横比
- 单文件 HTML，中文界面，字体只用系统栈（Tauri 离线，不能依赖网络字体）

## 已知约束

- 保留 4 个页签：软件管理 / 卸载历史 / 应用权限 / 设置
- 保留现有交互逻辑（AI gate、强制删除、还原点、逐项审核），方向只改呈现
- 现有色彩语义要延续：graphite 底 + amber 强调 + 红（危险）/ 绿（安全）/ 橙（警告）
- 现有字体栈可延续：Space Grotesk（拉丁）+ JetBrains Mono（等宽）+ Microsoft YaHei UI（中文）
- 可读性底线：正文 ≥13px（工具类高密度界面，用户是专业用户）、标签 ≥11px、
  正文对比度 ≥4.5:1（现有 `--dimmer #545B68` 是 3.1:1，**必须修**）

## 图片需求

**不需要摄影素材和插画**。这个题材的主角是数据本身：软件清单、路径、判定、状态。
凡是需要"图"的地方，用**数据可视化或程序化图形**（格线、刻度、状态灯、条形）代替，
不用 AI 生图，不用 emoji，不用装饰性插画。

## 三个方向必须同样解决的五件事

1. 导航从「四个 unicode 字符」变成能一眼认出的入口
2. 右侧详情栏不再常年空白
3. AI 状态从 8px 圆点变成看得见的硬约束
4. 受保护 / 危险 / 谨慎三种状态在同一视觉体系里可区分
5. 列表密度与可读性同时达标（对比度修到 4.5:1 以上）
